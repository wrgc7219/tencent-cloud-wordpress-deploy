## 用 WordPress 镜像部署：从创建实例到发布第一篇文章

在轻量应用服务器控制台创建实例时选 WordPress 应用镜像，1～3 分钟实例就能创建完成。之后进实例详情页的「应用管理」，能看到管理员地址和用户名，初始密码首次需要通过远程连接获取。

具体步骤：

1. 购买时选地域（广州、上海、北京等离你近的节点）和应用镜像 WordPress，套餐选 2核2GB
2. 创建完成后进入「应用管理」标签，记下管理员地址和用户名
3. 浏览器打开 `http://你的服务器IP/wp-admin`，输入账号密码登录
4. 到「设置 → 常规」修改站点标题和副标题；「设置 → 固定链接」选「文章名」格式，对 SEO 友好
5. 「外观 → 主题」挑一个响应式模板，手机和电脑都能正常显示
6. 「文章 → 写文章」，发布第一篇内容

> 绑定域名后，记得回「设置 → 常规」把 WordPress 地址和站点地址改成域名，否则页面资源可能还在走 IP。

插件不用装太多。缓存和备份各一个就够，比如 WP Super Cache 和 UpdraftPlus，装多了反而拖慢速度。

## 域名、解析、备案：让网站能被别人打开

服务器上跑起来只是第一步。别人要通过域名访问你的网站，还得完成三件事：注册域名并实名认证、把域名解析到服务器 IP、国内服务器完成 ICP 备案。少一件，网站都打不开。

**域名注册**：在腾讯云域名注册页查想要的名字，首年通常几十元。买完做实名认证，这是后续备案的前提。

**域名解析**：进 DNSPod 控制台添加 A 记录，主机记录填 `@`（主域名）和 `www`（子域名），记录值填服务器的公网 IP。解析生效通常需要几分钟到 1 小时。

**ICP 备案**：服务器在中国大陆境内就必须备案。腾讯云提供免费备案服务，按控制台提示提交资料，参考周期 7～23 个工作日。不想等的另一个选项是香港地域节点，购买后可以直接用 IP 访问，代价是国内访问速度可能不如大陆节点。

**HTTPS**：在腾讯云 SSL 证书控制台申请免费的 TrustAsia DV 证书，选 DNS 验证，在 DNSPod 加一条对应的 TXT 记录，签发后在控制台或 WordPress 里配置证书，并开启强制 HTTPS 跳转。

**公安备案**：ICP 备案通过后还有一步，网站开通之日起 30 日内到全国公安机关互联网站安全管理服务平台完成公安备案。这一步不少教程不提，但它是规定动作。

## 两个新手最常卡住的地方

网站打不开，九成是安全组没放行端口；后期想改环境却无从下手，多半是当初选镜像时没想清楚。这两件事都可以在购买阶段规避。

**安全组端口**。Linux 实例至少要放行 22（SSH 远程登录）、80（HTTP）、443（HTTPS）；Windows 实例还要加 3389（远程桌面）。80 端口没开，域名解析再正确也访问不了网站。在实例详情页的安全组里添加入站规则即可。

**应用镜像还是纯净系统**。腾讯云官方文档推荐直接用 WordPress 镜像，省去装环境的步骤；也有建站教程建议选 Debian 12 这类纯净系统，理由是应用镜像的安装细节不透明，后期想自定义配置时会不知道从哪下手。判断标准很简单：短期只想把网站跑起来，选 WordPress 镜像；打算长期维护、自己调 PHP 版本和 Nginx 配置，选纯净系统装宝塔面板。

## 什么情况下值得手动搭 LNMP

需要自定义软件版本、跑特定程序，或者想把服务器环境完全握在自己手里时，手动搭建更合适。代价是要多花一两个小时，还得懂一点 Linux。

最常见的做法是装宝塔面板，用可视化界面管理站点和数据库：

bash
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh


装完后在面板里创建站点、绑定域名，上传 WordPress 安装包解压到站点根目录，再按页面提示填数据库信息完成安装。LNMP 指的是 Linux + Nginx + MySQL/MariaDB + PHP 这套组合，WordPress 和 Discuz! 都跑在类似环境上。

宝塔的安装命令会随版本更新，执行前以其官网最新命令为准。

## 常见问题

**腾讯云服务器搭建个人网站最低要多少钱？**
按当前参考价，轻量应用服务器 2核2GB/3Mbps 是 459 元起/年，CVM 2核2GB/1Mbps 是 531 元起/年，域名首年几十元，备案免费。第一年总支出在几百元。

**一定要备案吗？**
服务器在中国大陆境内就必须完成 ICP 备案。选香港地域可以跳过备案，购买后直接用 IP 访问。

**1核1G 的配置够不够？**
腾讯云官方建站指南给出的入门推荐是 2核2GB。WordPress 装插件、开页面缓存之后对内存有要求，如果网站只是几篇静态页面、访问量很小，更低配置可以试，但余量不多。

**网站打不开，先查什么？**
按顺序查三样：安全组有没有放行 80 和 443 端口、域名解析是否生效、备案是否通过。大多数「服务器没问题但网站打不开」都卡在第一项。

**WordPress 和 Discuz! 怎么选？**
WordPress 是 PHP 开发的博客和内容管理程序，适合写文章、做展示站；Discuz! 是 PHP+MySQL 的论坛程序，适合做社区。个人网站绝大多数场景选 WordPress。
